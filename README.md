# LLM Hardware Benchmarks

Open dataset of consumer and prosumer hardware benchmarks for running large language models locally. Curated by [Trenin Labs](https://llmrequirements.com) and used to power [LLMRequirements.com](https://llmrequirements.com).

Released under [CC BY 4.0](LICENSE).

The initial dataset is being added in [PR #1](https://github.com/Trenin-Labs/LlmRequirements/pulls) — schema docs and contribution guide land with it.
